# WKT to KML Converter

A single-page, client-side tool that converts WKT (Well-Known Text) geometries into a KML document. No build step, no dependencies, no server - it's one index.html file.

Supports POINT, LINESTRING, POLYGON (with holes), MULTIPOINT, MULTILINESTRING, MULTIPOLYGON, and GEOMETRYCOLLECTION.

## Run it locally

Just open index.html in a browser, or visit the live GitHub Pages site once it's enabled.

## Live site

Enable GitHub Pages for this repo under Settings, then Pages. Set Source to "Deploy from a branch", pick the main branch and the root folder, then Save. The site will publish at the MbasaFaku.github.io/wkt-to-kml URL within a minute or two, and every future push to main will redeploy it automatically.
